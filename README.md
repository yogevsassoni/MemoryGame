# 🧠 Memory Game - React

A fun, interactive memory card matching game built using **React**. Flip the cards, match the pairs, and try to complete the game in the fewest moves possible!

---

## 🚀 Features

- 🃏 4x4 memory card grid with cute emojis
- ♻️ Shuffle on every restart
- 🔄 Card flipping logic using React state
- 🎯 Move counter to track your performance
- 🏆 Victory screen when all pairs are matched
- 💡 Built with React Hooks (`useState`, `useEffect`)

---

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/react-memory-game.git
cd react-memory-game
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm start
```

The game will open at [http://localhost:3000](http://localhost:3000)
